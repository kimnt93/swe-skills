# Rust + S3 / RustFS (aws-sdk-s3)

Adapter: `assets/template/crates/svc-infra/src/s3.rs`; settings: `.../config/s3.rs`; env: `assets/env/s3.env.example` ([env-config](env-config.md)). Tested live against RustFS.

`aws-sdk-s3` with static `Credentials`, `endpoint_url`, `force_path_style(true)`, and checksum calculation/validation set to `WhenRequired` (some
S3-compatible stores reject default trailing checksums). `put/get/list/delete/ping`; a missing key is `Error::NotFound`; buckets are provisioned by
the platform (`ensure_bucket` is for tests); bounded lists (`max_keys`); stream large objects instead of `collect`.


## Example usage

- “Store each report as JSON in the artifacts bucket and return its key.”
