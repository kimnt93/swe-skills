# Go + S3 (RustFS, AWS SDK v2)

*Verified with: aws-sdk-go-v2 and a live RustFS container (scaffold e2e test). The checksum setting is required for stores that reject the SDK's default trailing checksums.*

Reference: `assets/template/internal/infrastructure/s3x/s3.go`, `assets/template/internal/config/` (loader), `assets/env/s3.env.example`. The same code is compiled and tested in
the scaffold template. Nothing outside `internal/infrastructure/s3x` imports the SDK.

## Environment (load from env)

```bash
# assets/env/s3.env.example
S3_ENDPOINT=http://127.0.0.1:9000    S3_REGION=us-east-1    S3_BUCKET=example-local    S3_FORCE_PATH_STYLE=true
S3_ACCESS_KEY=     S3_SECRET_KEY=     # SECRETS: required, no default, never committed; Swarm: S3_ACCESS_KEY_FILE / S3_SECRET_KEY_FILE
```

```go
l := config.NewLoader(nil)
s3Cfg := config.LoadS3(l)                  // assets/template/internal/config/s3.go
if err := l.Err(); err != nil { return err }   // names every missing variable, never a value
objects := s3x.Open(s3Cfg)
```

## Rules

1. **Endpoint and credentials come from the environment only** (`S3_ENDPOINT`, `S3_ACCESS_KEY[_FILE]`, `S3_SECRET_KEY[_FILE]`).
   Static credentials via `credentials.NewStaticCredentialsProvider`; no default keys, no shared credentials file inside containers.
2. **Path-style addressing for RustFS/MinIO** (`S3_FORCE_PATH_STYLE=true` -> `o.UsePathStyle = true`): `http://host:9000/<bucket>/<key>`.
   Virtual-hosted style needs wildcard DNS for `<bucket>.host`.
3. **Checksums:** set `RequestChecksumCalculation` and `ResponseChecksumValidation` to `WhenRequired`. Newer SDK versions add trailing
   CRC checksums by default, which some S3-compatible stores reject.
4. **Use the endpoint through `BaseEndpoint`** (`s3.Options.BaseEndpoint`), not the removed global endpoint resolvers.
5. **Keys:** `<domain>/<yyyy>/<mm>/<id>.<ext>`, lower-case, no leading slash, no user-controlled raw strings (limit length, no `..`).
   Put content type on write. Never rely on listing order or consistency tricks: store the keys you need in PostgreSQL.
6. **Errors:** map `NoSuchKey` to `ErrNotFound` (`errors.As(err, *types.NoSuchKey)`); wrap everything else with `%w`; never return SDK
   text to clients. Every call takes `ctx` with a deadline.
7. **Big objects stream:** `GetStream` returns the body (caller closes it, errcheck-clean `defer func() { _ = rc.Close() }()`); use the
   SDK's multipart upload manager (`feature/s3/manager`) for large writes. Do not `io.ReadAll` a multi-GB object.
8. **Bounded lists:** `ListObjectsV2` with `MaxKeys`; page with the continuation token; never list a whole bucket on a request path.
9. **Provisioning:** buckets are created by the platform/provisioning job, not by the service. `EnsureBucket` exists for tests
   and local setup only. Health: `HeadBucket` is the `s3` check of `/healthz`.
10. **Idempotent keys** (content hash or deterministic id) make retries and replays safe.
