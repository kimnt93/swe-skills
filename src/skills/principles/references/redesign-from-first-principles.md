# Redesign From First Principles

Design as if the requirement had been known on day one, instead of bolting it on.

- Sketch the shape you would build today (the **architect** skill), then compare it with the current one.
- If the gap is small, migrate to the new shape in verifiable steps (the **sequence-verifiable-units** principle).
- Signs you are bolting on: a new boolean flag threaded through five functions, a special case in every handler, a second table that mirrors the first.
