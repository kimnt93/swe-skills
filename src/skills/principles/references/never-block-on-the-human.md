# Never Block on the Human

Proceed, show the result, and let the human course-correct.

- Reversible work (a branch, a worktree, a draft PR, a local migration) needs no permission.
- A question you can answer by running something is not the human's question: run it (the router's prototype playbook).
- Ask only for irreversible actions (production data, deploys, force-pushes to shared branches, money-path merges) and for real product calls.
