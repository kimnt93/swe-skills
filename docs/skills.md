## API and deployment

### api-contract

The HTTP API contract of the platform and how to refactor a service to it. Every API is versioned (/v1, /v2) with Swagger at /docs and one /healthz at the root that shows node, status, service name, env name, the served versions and non-secret config; internal callers send `x-internal-service-token` (plain or `Bearer`) plus `x-user-id` / `x-username`, and `GET /internal` is the token-protected health that shows the caller; it always listens on port 3000; the public host is {service_name}.{env_name}.{host} (orders-api.stg.@DOMAIN@) and the Traefik Host rule is labelled with the service name. Use when creating an API, adding a version, adding or fixing healthz or Swagger docs, changing the port or host, or auditing and refactoring an existing API project (Go, Python, Rust, TypeScript) to this contract, with an audit script and a live probe.
